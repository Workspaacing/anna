# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue. Go to
[Report a vulnerability](https://github.com/Workspaacing/anna/security/advisories/new) on this
repository's **Security** tab. Only you and the maintainers can see the report, and the conversation
about it happens there.

Include:

- what is affected and what an attacker could do with it;
- the steps to reproduce it;
- the Anna version, from **About Anna** in the app menu, and your operating system.

## Supported versions

Fixes are released in a new version of Anna. Anna offers each new release when it checks for
updates, and every release is on the [releases page](https://github.com/Workspaacing/anna/releases).
Older versions do not receive fixes.

## Verifying a download

Every release file is built by the public
[release workflow](https://github.com/Workspaacing/anna/actions/workflows/release.yml), and the
release page lists each file's SHA-256 digest. Compare it with the digest of the file you
downloaded before running it.
